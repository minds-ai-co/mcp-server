# Archived — retired Dedalus Labs marketplace build

This repository was a standalone build of the Minds MCP server, synced from the
main application for the Dedalus Labs MCP marketplace. That distribution channel
was retired on 2026-06-27 and this repository was archived on 2026-08-29. The
tool list here is out of date.

The Minds MCP server is hosted and needs no installation:

- **Endpoint:** `https://getminds.ai/mcp` (streamable HTTP)
- **Setup guide:** https://getminds.ai/mcp/setup
- **Docs & client manifests:** https://github.com/minds-ai-co/minds-mcp
